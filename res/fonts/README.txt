FONT CHỮ KILL-STREAK (First Blood / Double Kill / Triple Kill)
================================================================

Để chữ hiện ra ĐÚNG KIỂU BRUSH như ảnh mẫu, hãy:

1. Tải file font brush trong ảnh về (định dạng .ttf hoặc .otf).
2. Đổi tên thành:  killstreak.ttf
3. Bỏ vào thư mục này:  res/fonts/killstreak.ttf

Game sẽ tự nạp font này khi hiện chữ chuỗi hạ gục.

Nếu KHÔNG có file killstreak.ttf, game vẫn chạy bình thường và
dùng tạm font "Segoe Script" (in nghiêng đậm) làm dự phòng,
vẫn giữ đúng kiểu chữ trắng + viền đỏ như ảnh, chỉ khác dáng chữ.

Gợi ý tìm font: tìm "grunge brush font" hoặc "kill streak font"
trên dafont.com — chọn font miễn phí có dáng nét cọ giống ảnh.
